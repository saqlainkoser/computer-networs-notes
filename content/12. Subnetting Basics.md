**Subnetting** is the process of dividing a large network into smaller, more manageable sub-networks (called **subnets**). It is done by borrowing bits from the host portion of an IP address to create additional network divisions.

---

## Why Subnetting is Needed

1. **Efficient IP Address Utilization** – Avoids wasting large blocks of addresses on small networks.
2. **Reduced Network Traffic** – Broadcast traffic stays within a subnet instead of flooding the entire network.
3. **Improved Security** – Subnets can be isolated from each other; a problem in one subnet doesn't directly affect others.
4. **Better Organization** – Networks can be divided logically (e.g., by department: HR, Sales, IT).
5. **Simplified Management & Troubleshooting** – Easier to isolate and fix issues within a smaller subnet.

---

## Key Concepts

### IP Address Structure

Every IP address has two parts:

- **Network portion** – identifies the network
- **Host portion** – identifies the specific device within that network

Subnetting works by "borrowing" bits from the host portion and giving them to the network portion, creating additional smaller networks.

### Subnet Mask

A subnet mask determines which part of an IP address is the network portion and which part is the host portion.

```
IP Address:   192.168.1.10
Subnet Mask:  255.255.255.0
```

- `255` in an octet = that octet is fully part of the **network**
- `0` in an octet = that octet is fully part of the **host**

### CIDR Notation

Subnet masks can also be written in **CIDR (Classless Inter-Domain Routing)** shorthand — a slash followed by the number of network bits.

| Subnet Mask     | CIDR Notation |
| --------------- | ------------- |
| 255.0.0.0       | /8            |
| 255.255.0.0     | /16           |
| 255.255.255.0   | /24           |
| 255.255.255.128 | /25           |
| 255.255.255.192 | /26           |

Example: `192.168.1.0/24` means the first 24 bits are the network portion.

---

## How Subnetting Works (Concept)

Each time you **borrow one bit** from the host portion:

- The number of **subnets doubles**
- The number of **hosts per subnet is halved**

|Bits Borrowed|Subnet Mask|CIDR|No. of Subnets|Hosts per Subnet|
|---|---|---|---|---|
|0|255.255.255.0|/24|1|254|
|1|255.255.255.128|/25|2|126|
|2|255.255.255.192|/26|4|62|
|3|255.255.255.224|/27|8|30|
|4|255.255.255.240|/28|16|14|

_(Note: 2 addresses per subnet are always reserved — one for the **Network Address** and one for the **Broadcast Address** — so usable hosts = total addresses − 2)_

---

## Basic Formulas (for reference)

- **Number of Subnets** = 2^(borrowed bits)
- **Number of Hosts per Subnet** = 2^(remaining host bits) − 2

_(The "−2" accounts for the network address and broadcast address, which can't be assigned to devices.)_

---

## Simple Example

Suppose you have the network: `192.168.1.0/24` and you want to divide it into **4 subnets**.

1. To get 4 subnets, you need to borrow **2 bits** (since 2² = 4).
2. New subnet mask becomes: `255.255.255.192` → `/26`
3. Each subnet will have `2^6 = 64` addresses (62 usable hosts, after removing network & broadcast addresses).

**Resulting subnets:**

|Subnet|Network Address|Usable Host Range|Broadcast Address|
|---|---|---|---|
|1|192.168.1.0|192.168.1.1 – 192.168.1.62|192.168.1.63|
|2|192.168.1.64|192.168.1.65 – 192.168.1.126|192.168.1.127|
|3|192.168.1.128|192.168.1.129 – 192.168.1.190|192.168.1.191|
|4|192.168.1.192|192.168.1.193 – 192.168.1.254|192.168.1.255|

## Important Terms

|Term|Meaning|
|---|---|
|**Network Address**|The first address in a subnet; identifies the subnet itself (cannot be assigned to a device)|
|**Broadcast Address**|The last address in a subnet; used to send data to all devices in that subnet (cannot be assigned to a device)|
|**Usable Host Range**|The addresses between Network and Broadcast addresses that can be assigned to devices|
|**CIDR**|Notation for representing subnet masks as a slash + number of network bits|
|**VLSM**|Variable Length Subnet Masking — allows subnets of different sizes within the same network for efficient address use|

## Advantages of Subnetting

- Reduces wasted IP addresses.
- Limits broadcast traffic to smaller segments.
- Improves network security through isolation.
- Makes large networks easier to manage and troubleshoot.
- Allows better organization based on departments, floors, or locations.

## Disadvantages of Subnetting

- Adds complexity to network design and configuration.
- Requires careful planning to avoid wasting addresses or running out of subnets.
- Misconfiguration can lead to connectivity issues between subnets (routing between subnets requires a router/Layer 3 device).

---

## Summary

- Subnetting divides a large network into smaller subnets by borrowing bits from the host portion of an IP address.
- The **subnet mask** (or CIDR notation) defines the network vs. host boundary.
- Borrowing more bits = more subnets, but fewer hosts per subnet.
- Every subnet reserves one address for the **network** and one for **broadcast**.
- Subnetting improves address efficiency, security, traffic management, and network organization.
