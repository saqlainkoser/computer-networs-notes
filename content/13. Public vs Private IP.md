# Public vs Private IP Addresses

Every device connected to a network needs an IP address. Based on where and how they are used, IP addresses are classified into two main types: **Public IP** and **Private IP**.

---

## Public IP Address

### Definition

A **Public IP address** is an address that is **directly accessible over the internet**. It is unique across the entire internet and is assigned by an **ISP (Internet Service Provider)**.

### Key Points

- Globally unique — no two devices on the internet can have the same public IP at the same time.
- Used to identify a network (or device) on the internet.
- Assigned by the ISP, either dynamically (changes periodically) or statically (fixed, usually at extra cost).
- Websites, servers, and anything meant to be accessible from anywhere on the internet uses a public IP.

### Example

```
49.36.XX.XX   (the IP that shows up when you search "what is my IP" on Google)
```

---

## Private IP Address

### Definition

A **Private IP address** is used only **within a local network** (like a home, office, or organization) and is **not routable on the internet**.

### Key Points

- Not visible or accessible directly from outside the local network.
- Can be reused across different networks — many homes/offices can use the same private IP range without conflict, since each is isolated within its own LAN.
- Assigned by the local router (usually via DHCP) to devices within the network.
- Devices with private IPs access the internet through **NAT (Network Address Translation)** via the router.

### Reserved Private IP Ranges

|Range|Class|Total Addresses|
|---|---|---|
|10.0.0.0 – 10.255.255.255|Class A|~16 million|
|172.16.0.0 – 172.31.255.255|Class B|~1 million|
|192.168.0.0 – 192.168.255.255|Class C|~65,000|

### Example

```
192.168.1.5   (a device on a typical home Wi-Fi network)
```

---

## How They Work Together (NAT)

- Devices inside a home/office (phone, laptop, smart TV) each get a **private IP** from the router.
- When these devices access the internet, the router uses **NAT (Network Address Translation)** to translate all their private IPs into a **single public IP** for outbound communication.
- This allows multiple devices to share one public IP address, conserving the limited pool of public IPv4 addresses.

```
[Laptop: 192.168.1.5]  \
[Phone:  192.168.1.6]   >---- Router (NAT) ----> Internet (Public IP: 49.36.XX.XX)
[TV:     192.168.1.7]  /
```

---

## Comparison Table

|Aspect|Public IP|Private IP|
|---|---|---|
|**Visibility**|Accessible over the internet|Accessible only within the local network|
|**Uniqueness**|Globally unique|Can repeat across different private networks|
|**Assigned By**|ISP|Local router / network administrator|
|**Cost**|May involve extra cost (especially static IP)|Free, auto-assigned|
|**Security**|More exposed, directly reachable|More secure, hidden behind NAT/router|
|**Routable on Internet**|Yes|No|
|**Example**|49.36.XX.XX|192.168.1.5|

---

## Why Private IPs Exist (Significance)

1. **IPv4 Conservation** – Since public IPv4 addresses are limited (~4.3 billion), private IPs let multiple devices share one public IP via NAT.
2. **Security** – Devices behind a private IP are not directly exposed to the internet, reducing the attack surface.
3. **Simplified Internal Networking** – Organizations can freely design their internal IP addressing scheme without needing public address allocation.
4. **Cost Efficiency** – Businesses don't need to pay for a public IP for every single device.

---

## Summary

- **Public IP** = unique, internet-facing address assigned by an ISP; used to identify a network/device globally.
- **Private IP** = local-only address used within a home/office network; not directly reachable from the internet.
- **NAT** bridges the two — allowing many private-IP devices to share a single public IP for internet access.
