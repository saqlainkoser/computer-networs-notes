# Network Devices

Network devices are hardware components that enable communication, connectivity, and data transfer between computers and other devices within a network. Each device operates at a specific layer of the OSI model and performs a distinct function.

---

## Quick Reference Table

| Device       | OSI Layer     | Main Function                                             |
| ------------ | ------------- | --------------------------------------------------------- |
| Repeater     | Physical (1)  | Amplifies/regenerates signals                             |
| Hub          | Physical (1)  | Broadcasts data to all connected devices                  |
| Bridge       | Data Link (2) | Connects/filters traffic between two network segments     |
| Switch       | Data Link (2) | Forwards data to specific devices using MAC addresses     |
| Router       | Network (3)   | Routes data between different networks using IP addresses |
| Gateway      | All layers    | Connects networks using different protocols               |
| Modem        | Physical (1)  | Converts digital signals to analog and vice versa         |
| Access Point | Data Link (2) | Provides wireless connectivity to a wired network         |
| NIC          | Data Link (2) | Connects a device to a network                            |

---

## 1. Repeater

### Function

- Regenerates and amplifies weak signals so they can travel longer distances without loss of quality.
- Operates at the **Physical Layer**.

### Key Points

- Does not filter or modify data — simply boosts the signal.
- Used to extend the range of a network (e.g., in long cable runs or Wi-Fi range extension).
- Does not reduce network traffic or add intelligence to the network.

---

## 2. Hub

### Function

- A simple device that connects multiple devices in a network and broadcasts incoming data to **all** connected ports.
- Operates at the **Physical Layer**.

### Key Points

- Does not check destination address; sends data to every device (causes unnecessary traffic).
- Cannot filter data, leading to collisions in larger networks.
- Two types: **Active Hub** (amplifies signal) and **Passive Hub** (no amplification).
- Largely obsolete now, replaced by switches.

---

## 3. Bridge

### Function

- Connects two or more network segments (often of the same type) and filters traffic between them based on **MAC addresses**.
- Operates at the **Data Link Layer**.

### Key Points

- Reduces network traffic by only forwarding data meant for the other segment.
- Divides a large network into smaller, more manageable segments (collision domains).
- Slower than switches since it has fewer ports.

---

## 4. Switch

### Function

- An intelligent device that connects multiple devices in a network and forwards data only to the specific device it's intended for, using **MAC addresses**.
- Operates at the **Data Link Layer** (Layer 3 switches also handle routing).

### Key Points

- Reduces network congestion compared to a hub.
- Maintains a MAC address table to determine where to send data.
- Supports full-duplex communication (send/receive simultaneously).
- Commonly used to build LANs (Local Area Networks).

---

## 5. Router

### Function

- Connects two or more different networks and forwards data packets between them based on **IP addresses**.
- Operates at the **Network Layer**.

### Key Points

- Determines the best path for data using routing tables and routing protocols.
- Connects a LAN to the Internet (WAN).
- Can perform functions like **NAT (Network Address Translation)** and **firewall filtering**.
- Essential device for home and enterprise internet connectivity.

---

## 6. Gateway

### Function

- Acts as an entry/exit point between two networks that use **different protocols**, translating data formats as needed.
- Can operate at **any layer** of the OSI model, depending on the type.

### Key Points

- More complex than a router; performs protocol conversion.
- Example: connecting an internal email system to the Internet, or connecting different network architectures (e.g., TCP/IP to legacy systems).
- Often used as a general term for a network's "default gateway" (router) that connects it to external networks.

---

## 7. Modem (Modulator-Demodulator)

### Function

- Converts digital signals from a computer into analog signals for transmission over telephone/cable lines (**modulation**), and converts incoming analog signals back into digital (**demodulation**).
- Operates at the **Physical Layer**.

### Key Points

- Essential for connecting to the Internet via ISPs (DSL, cable, fiber).
- Types: **Dial-up, DSL, Cable, Fiber modem**.
- Often combined with a router in a single device (modem-router combo).

---

## 8. Access Point (AP)

### Function

- Allows wireless devices (Wi-Fi enabled) to connect to a wired network.
- Operates at the **Data Link Layer**.

### Key Points

- Extends network coverage wirelessly.
- Acts as a bridge between wired and wireless segments of a network.
- Multiple APs can be used to provide seamless coverage over a large area.

---

## 9. Network Interface Card (NIC)

### Function

- A hardware component that allows a device (computer, printer, etc.) to connect to a network.
- Operates at the **Data Link Layer**.

### Key Points

- Each NIC has a unique **MAC address**.
- Can be wired (Ethernet NIC) or wireless (Wi-Fi NIC).
- May be built into the motherboard or added as an expansion card/USB adapter.

---

## Comparison: Hub vs Switch vs Router

|Feature|Hub|Switch|Router|
|---|---|---|---|
|**OSI Layer**|Physical|Data Link|Network|
|**Addressing**|None|MAC address|IP address|
|**Data Forwarding**|Broadcasts to all ports|Sends to specific device|Routes between networks|
|**Intelligence**|None|Moderate|High|
|**Collision Domain**|Single (shared)|Separate per port|Separate per port|
|**Speed**|Slow|Fast|Moderate (processing overhead)|

---

## Summary

- **Repeater/Hub** – basic signal handling at the Physical layer, no intelligence.
- **Bridge/Switch** – intelligent traffic filtering at the Data Link layer using MAC addresses.
- **Router** – connects different networks and routes data using IP addresses.
- **Gateway** – connects networks with different protocols; performs translation.
- **Modem** – converts digital signals to analog and back for internet connectivity.
- **Access Point** – provides wireless access to a wired network.
- **NIC** – enables a single device to physically connect to a network.
