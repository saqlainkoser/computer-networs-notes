# 🌐 Networking Protocols — Notes

A structured reference of the most important networking protocols, grouped by the **OSI layer** they operate at and by **purpose**.

> 📌 **Note:** A _protocol_ is a set of rules that defines how data is formatted, transmitted, and received across a network so that devices can communicate reliably.

---

## 🧱 OSI Model Quick Reference

|Layer|Name|Example Protocols|
|---|---|---|
|7|Application|HTTP, HTTPS, FTP, SMTP, DNS, DHCP|
|6|Presentation|SSL/TLS, JPEG, ASCII|
|5|Session|NetBIOS, RPC|
|4|Transport|TCP, UDP|
|3|Network|IP, ICMP, ARP|
|2|Data Link|Ethernet, PPP, Wi-Fi (802.11)|
|1|Physical|Bluetooth, USB, DSL|

> 💡 **Tip:** Remember the layers top-down with: **A**ll **P**eople **S**eem **T**o **N**eed **D**ata **P**rocessing.

## 🔵 Application Layer Protocols

### HTTP / HTTPS

- **HTTP** (Hypertext Transfer Protocol) — used to load web pages via **requests and responses**.
- **HTTPS** — HTTP secured with **TLS/SSL encryption**. **⚠️ Always prefer HTTPS** for anything handling sensitive data.
- Runs on **port 80** (HTTP) and **port 443** (HTTPS).

### FTP / SFTP

- **FTP** (File Transfer Protocol) — transfers files between client and server. **Not encrypted** by default.
- **SFTP** (SSH File Transfer Protocol) — same purpose, but **encrypted** via SSH.

### SMTP / IMAP / POP3

- **SMTP** — sends email (port 25).
- **IMAP** — retrieves email, keeps it synced across devices (port 143/993).
- **POP3** — downloads email to a single device, often removing it from the server (port 110).

### DNS

- **Domain Name System** — translates human-readable domain names (e.g. `google.com`) into **IP addresses**.
- Works over **UDP port 53** (TCP for larger queries like zone transfers).

### DHCP

- **Dynamic Host Configuration Protocol** — automatically assigns **IP addresses** to devices on a network.

## 🟢 Transport Layer Protocols

|Protocol|Connection Type|Reliability|Use Case|
|---|---|---|---|
|**TCP**|Connection-oriented|✅ Reliable, ordered, error-checked|Web browsing, email, file transfer|
|**UDP**|Connectionless|❌ No guarantee of delivery/order|Video streaming, gaming, VoIP|

> ⚠️ **Key difference:** TCP performs a **3-way handshake** (`SYN → SYN-ACK → ACK`) before sending data. UDP just **sends packets immediately** — faster, but less reliable.

---

## 🟠 Network Layer Protocols

- **IP (Internet Protocol)** — handles **addressing and routing** of packets across networks.
    - **IPv4** — 32-bit addresses (e.g. `192.168.1.1`).
    - **IPv6** — 128-bit addresses, created to solve **IPv4 address exhaustion**.
- **ICMP** — used for diagnostics and error reporting (e.g. the `ping` command).
- **ARP (Address Resolution Protocol)** — maps an **IP address to a MAC address** on a local network.

---

## 🟣 Data Link & Physical Layer Protocols

- **Ethernet** — wired LAN standard, defines how devices access the physical medium.
- **Wi-Fi (802.11)** — wireless LAN standard.
- **PPP (Point-to-Point Protocol)** — direct connection between two nodes, often used in dial-up/VPN.
- **Bluetooth** — short-range wireless protocol for peripherals.

---

## 🔐 Security-Related Protocols

|Protocol|Purpose|
|---|---|
|**SSL/TLS**|Encrypts data in transit (basis of HTTPS)|
|**SSH**|Secure remote login and command execution|
|**IPSec**|Encrypts and authenticates IP packets, commonly used in **VPNs**|
|**WPA2 / WPA3**|Wi-Fi network security standards|

> ⚠️ **SSL is deprecated** — modern systems use **TLS 1.2 or 1.3**. If you see "SSL" mentioned today, it usually really means TLS.

## 🧠 Key Takeaways

- **TCP = reliable, slower.** **UDP = fast, unreliable.** Choose based on whether accuracy or speed matters more.
- **DNS** is the "phonebook of the internet" — without it, you'd have to type raw IP addresses.
- **HTTPS is not optional** in modern web development — it protects data using TLS encryption.
- Every protocol operates at a specific **OSI layer**, which determines what problem it's solving (physical transmission vs. routing vs. application-level communication).
