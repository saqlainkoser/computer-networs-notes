☁️ Cloud Computing — Introduction

1. Concept of Cloud Computing

Cloud Computing is the delivery of computing services — servers, storage, databases, networking, software, and analytics — over the Internet ("the cloud") instead of using local computers or personal servers/hard drives.

In simple terms: instead of storing files or running programs on your own device, you use remote servers hosted by a provider (like Google, Amazon, or Microsoft), accessed via the Internet, and you typically pay only for what you use.

1.1 Key Idea Behind the Concept

  • On-Demand: Resources (storage, computing power) can be accessed anytime, from anywhere with an Internet connection.
  • Shared Resources: A pool of computing resources is shared among many users (multi-tenancy).
  • Remote Servers: Data and applications live on data centers owned by cloud providers, not on your personal device.
  • Pay-as-you-go: Most cloud services charge based on actual usage rather than a fixed cost.

4. Basic Types of Cloud Services

Cloud services are generally divided into three main models, often visualized as layers — each offering a different level of control vs. convenience.

SaaS – Software as a Service (Least control, most convenience)
PaaS – Platform as a Service (Balanced)
IaaS – Infrastructure as a Service (Most control, least convenience)

4.1 IaaS (Infrastructure as a Service)

Definition: Provides virtualized computing infrastructure — servers, storage, and networking — over the Internet. Users manage operating systems, applications, and data, while the provider manages the physical hardware.

  • What's Provided by Vendor: Servers, storage, networking, virtualization
  • What User Manages: Operating system, middleware, runtime, applications, data
  • Best For: Companies needing flexible, scalable infrastructure without buying physical hardware
  • Examples: Amazon Web Services (AWS EC2), Microsoft Azure, Google Compute Engine

4.2 PaaS (Platform as a Service)

Definition: Provides a platform allowing developers to build, test, and deploy applications without worrying about underlying infrastructure (servers, storage, networking).

  • What's Provided by Vendor: Servers, storage, networking, OS, runtime environment, development tools
  • What User Manages: Applications and data only
  • Best For: Developers who want to focus on coding/app development without managing servers
  • Examples: Google App Engine, Microsoft Azure App Service, Heroku

4.3 SaaS (Software as a Service)

Definition: Delivers fully functional software applications over the Internet, accessible via a web browser, with no installation or maintenance required by the user.

  • What's Provided by Vendor: Everything — infrastructure, platform, and the application itself
  • What User Manages: Just their data/usage within the application
  • Best For: End users/businesses who want ready-to-use software without technical setup
  • Examples: Google Workspace (Gmail, Docs), Dropbox, Netflix, Microsoft 365, Zoom
