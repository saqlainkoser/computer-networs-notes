**IPv4 (Internet Protocol version 4)** is the fourth version of the Internet Protocol and the most widely used addressing scheme for identifying devices on a network. It provides a unique address to every device connected to a network, enabling data to be sent and received correctly.

---

## IPv4 Address Format

### Structure

- An IPv4 address is a **32-bit** numeric address.
- It is divided into **4 octets** (8 bits each), separated by dots — known as **dotted decimal notation**.
- Each octet ranges from **0 to 255** (2⁸ = 256 possible values per octet).

```
Format:  W . X . Y . Z
Example: 192.168.1.1

Binary form:
11000000.10101000.00000001.00000001
```

### Components of an IP Address

An IPv4 address consists of two parts:

1. **Network ID** – identifies the specific network.
2. **Host ID** – identifies a specific device within that network.

The split between Network ID and Host ID depends on the **class** of the address or the **subnet mask** used.

### Total Address Space

- Total possible addresses = 2³² = **4,294,967,296** (~4.3 billion addresses)
- Some are reserved for special purposes (private networks, loopback, multicast, etc.)

---

## IPv4 Address Classes

IPv4 addresses are divided into **5 classes (A to E)** based on the value of the first octet, primarily to accommodate networks of different sizes.

|Class|First Octet Range|Default Subnet Mask|Network/Host Bits|Purpose|
|---|---|---|---|---|
|**A**|1 – 126|255.0.0.0 (/8)|8 network / 24 host|Large networks (few networks, many hosts)|
|**B**|128 – 191|255.255.0.0 (/16)|16 network / 16 host|Medium-sized networks|
|**C**|192 – 223|255.255.255.0 (/24)|24 network / 8 host|Small networks (many networks, few hosts)|
|**D**|224 – 239|N/A|N/A|Multicasting|
|**E**|240 – 255|N/A|N/A|Reserved for research/experimental use|

_(Note: 127.x.x.x is reserved for loopback addresses and is not used as part of Class A for hosts.)_

### Class A

- **Range:** 1.0.0.0 – 126.255.255.255
- Supports **~16 million hosts** per network.
- Used by large organizations and ISPs.

### Class B

- **Range:** 128.0.0.0 – 191.255.255.255
- Supports **~65,000 hosts** per network.
- Used by medium to large organizations, universities.

### Class C

- **Range:** 192.0.0.0 – 223.255.255.255
- Supports **254 hosts** per network.
- Used by small businesses and home networks.

### Class D

- **Range:** 224.0.0.0 – 239.255.255.255
- Reserved for **multicast groups** (sending data to multiple destinations simultaneously, e.g., video streaming).

### Class E

- **Range:** 240.0.0.0 – 255.255.255.255
- Reserved for **experimental and research purposes**; not used for public addressing.

## Special / Reserved IPv4 Addresses

|Address/Range|Purpose|
|---|---|
|0.0.0.0|Default/unspecified address|
|127.0.0.1|Loopback address (localhost)|
|10.0.0.0 – 10.255.255.255|Private network (Class A)|
|172.16.0.0 – 172.31.255.255|Private network (Class B)|
|192.168.0.0 – 192.168.255.255|Private network (Class C)|
|255.255.255.255|Limited broadcast address|
|169.254.0.0 – 169.254.255.255|APIPA (Automatic Private IP Addressing)|

## Significance of IPv4 Addressing

1. **Unique Identification** – Every device on a network gets a unique address, allowing accurate delivery of data.
2. **Routing** – Enables routers to determine the best path to forward packets between networks based on Network ID.
3. **Network Segmentation** – Classes and subnetting allow large networks to be divided into smaller, manageable sub-networks.
4. **Efficient Address Allocation** – Class-based system originally allowed organizations to be assigned address blocks matching their size needs.
5. **Foundation of the Internet** – IPv4 remains the backbone addressing system for most of the internet's infrastructure, despite the gradual shift to IPv6.
6. **Private vs Public Addressing** – Enables organizations to use private IP ranges internally (via NAT) while conserving public IPv4 address space.

---

## Limitations of IPv4 (Why IPv6 is Emerging)

- Only supports **~4.3 billion** addresses, which is insufficient for the growing number of internet-connected devices.
- Class-based allocation was inefficient, wasting large blocks of addresses (largely solved later by **CIDR – Classless Inter-Domain Routing**).
- Leads to **IPv4 address exhaustion**, driving the adoption of **IPv6** (128-bit addressing).

---

## Summary

- IPv4 is a **32-bit address** written in **dotted decimal notation** (e.g., 192.168.1.1).
- Divided into **5 classes (A–E)**, mainly for network size categorization (A, B, C for general use; D for multicast; E for research).
- Each address has a **Network ID** and **Host ID** portion.
- Despite limitations and address exhaustion, IPv4 remains foundational to network communication, with private addressing and NAT helping extend its usability.
