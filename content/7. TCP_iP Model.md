# TCP/IP Model (Transmission Control Protocol / Internet Protocol Model)

The **TCP/IP Model** is a practical, real-world networking model developed by the **U.S. Department of Defense (DoD)**, on which the modern Internet is built. Unlike the OSI Model (which is conceptual), the TCP/IP model is **implementation-based** and consists of **4 layers**.

---

## The 4 Layers of TCP/IP Model

|Layer No.|Layer Name|Data Unit|Equivalent OSI Layers|
|---|---|---|---|
|4|Application|Data|Application, Presentation, Session|
|3|Transport|Segments|Transport|
|2|Internet|Packets|Network|
|1|Network Access (Link)|Frames/Bits|Data Link, Physical|

---

## 4. Application Layer

### Function

- Combines the functions of OSI's Application, Presentation, and Session layers.
- Provides network services directly to end-user applications and handles data formatting, encoding, and session management.

### Key Points

- Protocols: **HTTP, HTTPS, FTP, SMTP, DNS, Telnet, SNMP**
- Responsible for user interaction with the network (e.g., browsing, email, file transfer).

---

## 3. Transport Layer

### Function

- Provides reliable, end-to-end communication between source and destination devices.
- Handles **segmentation, flow control, and error control**.

### Key Points

- Two main protocols:
    - **TCP (Transmission Control Protocol)** – connection-oriented, reliable, ordered delivery, used for web browsing, email, file transfer.
    - **UDP (User Datagram Protocol)** – connectionless, faster, no delivery guarantee, used for streaming, gaming, VoIP.
- Uses **port numbers** to identify applications/services.

---

## 2. Internet Layer

### Function

- Responsible for **logical addressing, routing, and packet forwarding** across networks.
- Equivalent to the Network Layer in the OSI model.

### Key Points

- Uses **IP addresses** (IPv4/IPv6) to identify devices.
- Determines the best path for data using routing protocols.
- Protocols: **IP, ICMP, ARP, IGMP**
- Devices: **Routers**

---

## 1. Network Access Layer (Link Layer)

### Function

- Combines the functions of OSI's Data Link and Physical layers.
- Handles the physical transmission of data over the network medium and node-to-node delivery.

### Key Points

- Uses **MAC addresses** for physical device identification.
- Defines hardware specifications: cables, network cards, switches, signal transmission.
- Protocols: **Ethernet, Wi-Fi (802.11), PPP, ARP**
- Devices: **Switches, Hubs, NICs, Cables**

---

## How Data Flows Through the TCP/IP Model

1. **Sender side:** Data moves from **Application → Network Access** layer, with each layer adding its own header (**encapsulation**).
2. **Receiver side:** Data moves from **Network Access → Application** layer, with each layer removing the corresponding header (**decapsulation**).

```
Sender                              Receiver
Application   (Data)                Application
Transport     (Segments)            Transport
Internet      (Packets)             Internet
Network Access (Frames/Bits) -----> Network Access
```

---

## TCP/IP Model vs OSI Model

|TCP/IP Model (4 Layers)|OSI Model (7 Layers)|
|---|---|
|Application|Application, Presentation, Session|
|Transport|Transport|
|Internet|Network|
|Network Access|Data Link, Physical|

### Key Differences

|Aspect|TCP/IP Model|OSI Model|
|---|---|---|
|**Layers**|4|7|
|**Nature**|Protocol-based, practical implementation|Conceptual/reference model|
|**Developed by**|DoD (Department of Defense)|ISO (International Organization for Standardization)|
|**Usage**|Used in real-world networking (the Internet)|Used mainly for teaching/understanding concepts|
|**Approach**|Horizontal (protocol-focused)|Vertical (layer-focused)|
|**Reliability**|Depends on the layer (TCP reliable, UDP not)|Reliable communication guaranteed at Transport layer|

---

## Summary

- The TCP/IP Model has **4 layers**: Application, Transport, Internet, and Network Access.
- It is the **practical model** on which the entire Internet operates.
- Simpler and more implementation-focused compared to the 7-layer OSI Model.
- Core protocols **TCP** and **IP** give the model its name and form the backbone of internet communication.
