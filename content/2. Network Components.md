|             |                                                                                  |
| ----------- | -------------------------------------------------------------------------------- |
| Node        | Any device on a network — laptop, phone, printer, router, server                 |
| Link        | Medium connecting two nodes — Ethernet cable, Wi-Fi signal, fiber optic          |
| Bandwidth   | Maximum data transfer speed a link can support (e.g. 1 Gbps Ethernet)            |
| Throughput  | Actual data speed achieved in practice — always ≤ bandwidth                      |
| Latency     | Delay for data to travel from source to destination (measured in ms)             |
| Protocol    | Agreed set of rules for communication — like a common language both sides follow |
| Packet      | Data broken into small chunks for sending; reassembled at destination            |
| Port        | Number (0–65535) identifying which application data belongs to on a device       |
| IP Address  | Unique logical address of a device on a network — like a postal address          |
| MAC Address | Unique physical address burned into NIC by manufacturer — permanent fingerprint  |
